# Sistemas Dinâmicos Discretos

### Iniciação Científica | IME-USP

Pesquisa matemática com foco no estudo de sistemas dinâmicos discretos, teoria do caos, bifurcações e dinâmica simbólica.

</div>

## Sobre o Projeto
Este projeto tem como objetivo introduzir e aprofundar os conhecimentos em Sistemas Dinâmicos, servindo como preparação sólida para pesquisas e uma futura Pós-Graduação na área. 

## Bibliografia Principal
O estudo é fundamentado em tópicos clássicos da área, tendo como base principal a obra:
* *An Introduction to Chaotic Dynamical Systems* — Robert L. Devaney.
